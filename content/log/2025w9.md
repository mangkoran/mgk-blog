## Work

- Dev env migration
  - Restore RDS snapshot from different AWS account
    1. (target account) Create customer-managed KMS key and add permission for
       source account. Default AWS-managed key won't work with snapshot sharing
    1. (source account) Create snapshot (either from running DB or auto
       snapshot) using the key. Then share it with target account

## Other

- Started to learn Zig
  - So far its easy to understand
  - Error union concept is a bit different comparted to Rust and Go. It will
    return either a value or an error instead of struct of value and error
  - `try` and `catch` are refined around error union. We can use `catch` in
    an expression. And `try` is a shortcut to simply return caught error
